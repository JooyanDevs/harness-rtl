# harness-rtl

فارسی را در خودِ ابزارهای AI راست‌چین می‌کند؛ نه فقط در برنامه‌ای که با آن‌ها می‌سازید.

<p align="center"><strong>Claude Code · Qoder · Hermes · Codex · Cline · OpenCode · ZCode · Freebuff · DeepSeek · terminal</strong></p>

## مشکل

هارنس‌ها رابط خود را چپ‌به‌راست می‌سازند. نتیجه:

- جمله فارسی با یک شناسه انگلیسی در وسط، به‌هم‌ریخته می‌شود.
- متن فارسی چپ می‌چسبد و سه‌نقطه‌ی عنوان‌های بلند سمت اشتباه می‌افتد.
- دستورها یا مسیرها وقتی داخل جمله‌ی فارسی می‌آیند، روی هم می‌افتند.

## قانون

| متن | جهت |
|---|---|
| هر متن دارای حرف فارسی/عربی/عبری | راست‌چین |
| متن کاملاً انگلیسی یا کد | چپ‌چین، دست‌نخورده |
| ترکیب فارسی و انگلیسی | راست‌چین |

بلوک کد همیشه بایت‌به‌بایت دست‌نخورده می‌ماند تا کپی و اجرا نشکند.

## هر هارنس چه می‌گیرد

| هارنس | سطح | نتیجه |
|---|---|---|
| Claude Code | هوک `MessageDisplay` و اعلان `SessionStart` | ترتیب درست پاسخ‌ها |
| Qoder | هوک‌های `SessionStart` و `UserPromptSubmit` | پاسخ‌ها با `div dir=rtl` راست‌چین؛ رابط خود Qoder دست نمی‌خورد |
| Hermes | پلاگین دسکتاپ | راست‌چین واقعی، سه‌نقطه‌ی درست، وزیرمتن |
| Codex | فقط بلوک دستورالعمل | شکل درست خروجی؛ رندر دسکتاپ خودش bidi دارد |
| Cline | فایل قوانین سراسری | ترتیب درست؛ چت Cline اچ‌تی‌ام‌ال خام نشان نمی‌دهد |
| OpenCode | `AGENTS.md` + مهارت | ترتیب درست |
| ZCode | `AGENTS.md` + مهارت | ترتیب درست |
| Freebuff | `~/.knowledge.md` | ترتیب درست |
| DeepSeek Harness | `AGENTS.md` + مهارت | ترتیب درست |
| ترمینال | فقط بلوک دستورالعمل | ترتیب خوانا و کد کپی‌شدنی؛ ترمینال نمی‌تواند راست‌چین کند |

## نصب

```bash
git clone https://github.com/JooyanDevs/harness-rtl
cd harness-rtl
node install/rtl.js detect
node install/rtl.js install
node install/rtl.js verify
```

`install` این‌ها را انجام می‌دهد:

- آداپتر همان هارنس را کنار تنظیماتش کپی می‌کند؛
- یک بلوک مدیریت‌شده به `CLAUDE.md` / `AGENTS.md` اضافه می‌کند؛
- مهارت را در پوشه‌ی skills همان هارنس نصب می‌کند؛
- از هر فایلی که تغییر می‌دهد نسخه‌ی پشتیبان می‌گیرد.

### هیچ نرم‌افزار جداگانه‌ای نصب نمی‌شود

هر هارنس فقط از سطح توسعه‌ی خودش استفاده می‌کند: هوک، پلاگین، فایل قوانین یا مهارت. نه میان‌بر، نه لانچر، نه پردازه‌ی پس‌زمینه. برای Qoder فقط اگر Qoder را یک‌بار ببندید و دوباره باز کنید، هوک‌ها خوانده می‌شوند.

## فونت

CSS فونت را از سیستم می‌خواهد: `Vazirmatn`، `Vazirmatn RD`، `Vazirmatn UI` و در نهایت Segoe UI یا Tahoma.
فونت در مخزن قرار ندارد. اگر وزیرمتن نصب نباشد، متن درست می‌شود اما با فونت پیش‌فرض سیستم نمایش داده می‌شود.

این CSS فقط در Hermes اعمال می‌شود. پاسخ‌های Qoder با فونت خودِ Qoder نمایش داده می‌شوند؛ Qoder `style` و `<font>` را حذف می‌کند، پس هوک نمی‌تواند فونت پاسخ‌ها را عوض کند.

## به‌روزرسانی خودکار

هنگام تغییر نسخه‌ی یک هارنس:

```bash
node install/rtl.js check
```

این بررسی در Claude Code و Qoder خودکار است: هوک در شروع هر نشست آن را اجرا می‌کند. در بقیه‌ی هارنس‌ها بلوک قوانینِ نصب‌شده به مدل می‌گوید در شروع نشست همین دستور را اجرا کند و نتیجه را یک‌خطی به شما بگوید.

- کد خروج `0`: همه‌چیز تأییدشده است.
- کد خروج `2`: نسخه‌ی هارنس عوض شده یا نسخه‌ی نصب‌شده‌ی مهارت از مخزن عقب است. پیام می‌گوید مهارت را چطور به‌روز کنید: `install` و سپس `verify`. اگر PASS داد، همان نسخه تأیید و ثبت می‌شود. اگر FAIL داد، `skill/references/update.md` مسیر تعمیر و انتشار را می‌دهد.

خودِ به‌روزرسانی عمداً خودکار نیست: نسخه‌ی خراب نباید بی‌صدا روی همه‌ی هارنس‌ها پخش شود. یک دستور `install` همه‌ی نسخه‌های نصب‌شده را با هم به‌روز می‌کند.

## حریم خصوصی

فقط نسخه‌ها و مسیر فایل‌های تنظیمات خوانده می‌شود. پیام‌ها، تاریخچه، نشست‌ها، توکن‌ها و متغیرهای محیطی خوانده نمی‌شوند. هیچ داده‌ای به سرور نمی‌رود، هیچ پردازه‌ای در پس‌زمینه اجرا نمی‌شود و هیچ پورتی باز نمی‌ماند. جزئیات: [`skill/references/privacy.md`](skill/references/privacy.md).

حذف کامل:

```bash
node install/rtl.js uninstall
```

## ساختار

```
engine/       قانون جهت + رفع سطح DOM + رفع سطح خط
adapters/     کد ورودی Claude، Hermes و بقیه‌ی هارنس‌ها
dist/         خروجی تولیدشده و خودکفا برای هر هارنس
install/      نصب، بررسی، اعلان به‌روزرسانی، حذف
skill/        مهارت قابل استفاده در هارنس‌ها + هوک Qoder
tests/        قانون جهت، هوک متنی، همگامی dist، آزمون واقعی Chromium
```

`dist/` را دستی ویرایش نکنید:

```bash
node tools/build.js
node --test
```

## محدودیت‌ها

- ترمینال یک شبکه‌ی سلولی چپ‌به‌راست است؛ راست‌چین واقعی در آن ممکن نیست. برای خواندن طولانی فارسی از رابط گرافیکی استفاده کنید.
- یک جمله‌ی انگلیسی که فقط یک واژه‌ی فارسی نقل کرده باشد هم راست‌چین می‌شود؛ این خواسته‌ی صریح قانون است.
- هوک Claude استایل inline مارک‌داون را روی خطوط فارسی حذف می‌کند تا ترتیب درست بماند.
- Qoder متن پاسخ را راست‌چین می‌کند، نه کل رابط را؛ نوار کنار، دکمه‌ها و منوها چپ‌چین می‌مانند.
- در Cline، OpenCode، ZCode، Freebuff، DeepSeek و Codex فقط ترتیب متن درست می‌شود؛ این رابط‌ها HTML خام را رندر نمی‌کنند، پس تراز راست واقعی ندارند.
- Qoder اگر `style=""` یا `<font>` به‌کار ببرد حذف می‌شود؛ فقط `dir` و `align` می‌مانند.
